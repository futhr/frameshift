## Status vocabulary

**Research** means a direction or component is being investigated. **Candidate** means it appears suitable but has not passed physical validation. **Reference** describes an intended interoperable implementation, not a commercial product. **Prototype** means hardware/software built to validate assumptions.

Nothing is production-ready until physically tested and those results are documented.
