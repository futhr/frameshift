# Paper Frame — Reflective E-Paper Reference

**Status: research / premium future path + small prototype path**

## Purpose

Approach physical printed artwork: reflective rather than emissive, very thin at the display surface, and capable of retaining artwork with little/no display power between updates.

## Large-format goal

A2 is the desired large-format class. Large color e-paper/Spectra-class panels are currently much more expensive than commodity IPS, so this should not be the first full-size prototype.

## Small reference prototype

Use a smaller color e-paper development panel to validate Frame Protocol, palette negotiation, host quantization/dithering, refresh workflow, local persistence and power behavior.

A 13.3-inch-class color e-paper/Spectra reference remains a candidate; exact SKU/controller/availability must be revalidated before purchase.

## Future

28.5-inch/A2-class reflective color displays are a compelling end state, but exact hardware remains research because price and availability dominate.

The host sends panel-ready assets. Slow full refresh is acceptable: this frame is artwork, not video.

Monochrome large-format e-paper remains a supported capability class for intentionally graphic black-and-white work.
