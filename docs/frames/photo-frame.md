# Photo Frame — Matte IPS Reference

**Status: research / candidate prototype**

## Purpose

The inexpensive large-format reference. It validates mechanics, protocol, host workflow and artwork experience before expensive large e-paper.

## Physical target

A2-like wall presence. Current research direction is approximately 27-inch 16:9 raw matte IPS. ISO A2 is 420 x 594 mm, so passe-partout/frame design intentionally accommodates the aspect-ratio mismatch.

Requirements: raw panel, matte/anti-glare surface, wide viewing angle, no touch, no smart/vendor platform, QHD-class resolution preferred, and eDP preferred where practical.

## Electronics

A small network/frame agent feeds the display/controller path. The exact controller is deliberately not frozen. A commodity HDMI-to-eDP board is acceptable in the first prototype if it reduces cost/risk.

Avoid a full-size Raspberry Pi merely to show still artwork.

## Cost objective

Keep the first large prototype in the low-thousands-of-SEK range. All sourcing/prices require fresh validation before purchase.
