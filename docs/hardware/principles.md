# Hardware Principles

1. The frame comes first; electronics fit the artwork.
2. Prefer raw displays over finished plastic smart monitors.
3. Keep expensive compute off the frame.
4. Frames retain valid artwork without continuous streaming.
5. No Raspberry Pi by default; Linux SBCs require justification.
6. Prefer small embedded controllers where drivers permit.
7. Display-specific electronics are adapters, not architectural dependencies.
8. Thinness includes PSU, connectors, cable bends and thermal clearance.
9. Thermals are part of the frame, especially for emissive matrices.
10. Prototype cheaply before premium large-format panels.

Reference builds should record active area, panel outline, complete depth, controller/connector clearance, PSU dimensions, thermals, weight, mounting, service access and passe-partout geometry.
